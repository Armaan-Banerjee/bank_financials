# Bank financials

Financial data workbooks for 145 of 148 banks monitored by the PRA.

## Repository layout

- `banks/` — generated bank workbooks
- `data/reference/` — canonical source lists
- `deliverable/` — generated web deliverable
- `docs/reports/` — project analyses and build-effort reports
- `docs/project-notes/` — working issue and improvement notes
- `research/` — analysis data and experiments
- `scripts/` — workbook builders and the insights pipeline
- `server/` — local delivery service
