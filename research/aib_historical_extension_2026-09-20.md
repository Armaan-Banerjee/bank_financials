# AIB Group (UK) historical Pillar 3 extension

The AIB Group (UK) FY2019 and FY2020 workbooks are entity-specific Pillar 3 files, but they use the
pre-2022 EU disclosure format and EUR amounts. The current AIB workbook is deliberately a FY2021–FY2025
GBP series, so these figures must not be inserted into its current metric rows.

The FY2020 workbook's confirmed headline values are:

| Metric | FY2020 | Basis |
|---|---:|---|
| CET1 capital | €1,693m | AIB Group (UK) Pillar 3, Table 1 |
| Tier 1 capital | €1,693m | same |
| Total capital | €1,693m | same |
| Credit-risk RWA | €7,573m | same |
| Market-risk RWA | €0m | same |
| Operational-risk RWA | €605m | same |
| CVA RWA | €0m | same |
| Total RWA | €8,178m | same |
| Leverage exposure | €14,728m | Tables 4/5 |
| Leverage ratio | 11.5% | Table 5 |

The official source files are:

- https://aib.ie/content/dam/frontdoor/investorrelations/docs/resultscentre/pillar3/2020/aib-group-UK-2020-pillar-3-report.xlsx
- https://aib.ie/content/dam/frontdoor/investorrelations/docs/resultscentre/pillar3/pillar-3-2019-uk-300320.xlsx

The two files were subsequently downloaded and read directly. The AIB workbook now contains three
clearly separated auxiliary sheets — `Historical P3 Capital EUR`, `Historical P3 RWA EUR` and
`Historical P3 Leverage EUR` — covering FY2019 and FY2020. They are intentionally not merged into the
current GBP FY2021–FY2025 metric sheets. FY2019's leverage table prints Tier 1 capital of €1,612m,
while its Table 1 prints €1,613m; both values are retained on their respective source-basis rows.
