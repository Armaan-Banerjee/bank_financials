## Reconciliation and interpretation flags

- These are TheBanks.eu-calculated ratios, not bank-published KPIs. They must retain this provenance if later merged.
- Santander's FY2024 site ROA of 0.36% agrees with the exact bank-published figure already verified in the project.
- Tandem FY2023 ROA 0.12% and FY2024 ROA 0.33% / ROE 6.89% reconcile to the exact-bank audited inputs documented in the existing project audit.
- Turkish Bank UK FY2024 ROA 0.43% and ROE 2.62% reconcile exactly to the
  audited average-assets and average-equity calculations. The bank's own 2.61%
  FY2024 ROE uses year-end equity and remains a separate evidence class.
- United Trust Bank's FY2024 ROE of 40.59% is conspicuously high. It is retained exactly as published; the profile also shows a sharp fall in displayed equity, so denominator/timing must be checked before comparison with workbook calculations.
- The Bank of London Group's profile explicitly gives FY2024 ROA (-4.40%) but no ROE. A missing field remains null rather than being inferred.
- Secure Trust Bank and Shawbrook publish differently based measures in their own reports (continuing average-equity and tangible-equity returns respectively). TheBanks.eu ROE should not be silently treated as the same KPI.
- The three no-data entities are not necessarily missing profitability evidence overall: project research already contains bank-published returns for SMBC, State Bank of India (UK) Limited, and Turkish Bank (UK) Limited. This report records only what TheBanks.eu explicitly published for the exact entities.

## Method

Each project name was searched individually against normal TheBanks.eu search/profile routes. Identity was checked from the profile name and, where available, company number, history, or UK subsidiary wording. Parent companies, foreign branches, predecessor/successor entities outside the workbook perimeter, and similarly named banks were rejected. Live profile performance prose was treated as `thebanks_profile`; an older value was retained as `search_indexed` only when the indexed TheBanks.eu result explicitly stated the entity, year, and numeric ratio. Profile balance-sheet and profit figures were never used to calculate a missing ratio.
