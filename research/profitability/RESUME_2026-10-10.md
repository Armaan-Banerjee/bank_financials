## 3. The method, proven end-to-end on 36 banks

(4 in the curated store, plus 32 in wave 1 of the sweep.)

Per bank:

1. `curl` a candidate URL. **Verify it is really a PDF**: `%PDF` magic
   (`head -c 5 f.pdf | xxd -p` → starts `255044462d`) AND Content-Type. An
   HTTP 200 serving a homepage is a soft-404 and has fooled this project.
2. Prefer the most recent annual report. Companies House
   `.../document?format=pdf&download=0` URLs work with plain curl.
3. Text layer? `pdftotext f.pdf - | tr -d '[:space:]' | wc -c`
   - **Born-digital**: `pdftotext -layout`, grep `[Rr]eturn on|RoTE|ROE|ROA|
     return on average`. Digits are exact, but still render the page — the
     real risk is column/year misassignment and the footnote.
   - **Scan (zero bytes)**: **a grep finding nothing is NOT evidence the bank
     publishes none.** Render at 150 dpi, `tesseract` ONLY to find the KPI
     page, then 300 dpi that page.
4. `pdftoppm -r 300 -f P -l P -png -singlefile f.pdf out`, then **read the
   image**. Every recorded figure must have been seen at 300 dpi.
5. Record figure, **verbatim** definition, entity, printed + PDF page.

The KPI page sat at PDF page 3–6 in every report checked so far.

### Record shapes
See `published_returns.jsonl` — match it exactly. Four kinds: a figure;
`publishes_none:true`; `excluded:true` (wrong entity); `unresolved:true`.

### Non-negotiables
- **Entity discipline.** A GROUP figure is a different claim → `excluded`.
  Already bitten twice: Aldermore's 7.7% is Aldermore *Group*; Coutts' 21.7%
  is a NatWest Group *segment*.
- **`publishes_none` is a FINDING, not a failure.** Most small banks publish
  none. Record it with the evidence.
- **Capture comparatives**, marked `own_edition:false`. The own-edition rule
  applies to a published ratio exactly as to a transcribed figure.
- **Do not bypass access controls.** thebanks.eu is behind a Cloudflare
  CAPTCHA; some hosts return Akamai denials. Record as blocked and route to
  another public source. Distinguish from a mere server misconfiguration
  (an expired TLS cert is not an access control).
- **Read-only w.r.t. the corpus.** Never touch `banks/` or `scripts/`.
- Reproducing a figure arithmetically is a **hypothesis**, not a finding.
