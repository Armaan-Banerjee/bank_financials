## Question

When a CET1 ratio changes, is the main driver CET1 capital, total RWAs, or
both?

## Scope

- Build annual CET1 capital growth, RWA growth, and CET1-ratio change from
  `research/insights.db`.
- Add a four-quadrant HTML visual: RWA change on x, CET1 capital change on y,
  ratio change as colour, and latest capital as size where comparable.
- Show broad results by default; expose strict unit-and-basis-comparable
  results as a validation view.
- Include bank, FRN, period, unit, basis, source, and eligibility in the
  accessible table/trace view.

## Completion criteria

- HTML and PDF include the decomposition visual with comparable N and a table
  fallback.
- Ratio changes use percentage points; amount changes use an explicit
  relative/log scale.
- Missing, unknown-unit, and incompatible-basis cases remain explicit.
- Tests cover numerator-only, denominator-only, both-changing, missing, and
  incompatible cases; full tests and refresh remain green.

## Resolution

Closed 2026-08-30. Added `scripts/insights/in022_ratio_decomposition.py` with
database-derived broad and strict annual decomposition payloads. The analysis
requires consistent amount units, permits unknown basis only in broad mode,
and preserves explicit exclusions for missing observations, unknown units,
and basis incompatibility.

Integrated the broad scatter visual and strict validation table into the HTML
deliverable, plus a vector scatter chart and summary into the PDF. Source
notes, FRNs, units, bases, periods, and movement values are retained in the
HTML trace table. Added focused tests and pipeline assertions.

Live FY2023→FY2024 result: 85 broad-comparable and 69 strict-comparable bank
pairs. Full insights suite: 197 tests passing. Full `refresh_all.py` completed
successfully.
