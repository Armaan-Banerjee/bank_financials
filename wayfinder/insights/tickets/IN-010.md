## Question

Using IN-009's normalized strict/broad observations, quantify how entities
within each parent group differ at the latest comparable level and in trend
direction over time.

## Scope

- Compare latest comparable values within each group.
- Compare entity-level adjacent-year and long-run trend directions.
- Report within-group dispersion, agreement, coverage, and unresolved basis or
  entity caveats.
- Mark groups without enough comparable entities as insufficient rather than
  ranking them.
- Return machine-readable results for the deliverables; do not duplicate the
  normalization rules.

## Completion criteria

- Public query/output interface has regression tests for aligned, mixed,
  insufficient, and basis-mismatched groups.
- Results are sourced from SQLite and reconcile to IN-009 coverage counts.
- Parent-group membership and caveats remain traceable to the existing typed
  parent-group tables.
