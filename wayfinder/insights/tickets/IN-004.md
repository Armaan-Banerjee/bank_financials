## Question

Extend `../../Cross-Bank Trends Analysis.md` — currently based on 29 built
banks — to the full 145-bank dataset now available via IN-001's extraction
tool, and add a new within-parent-group comparison dimension using IN-002's
group mapping. This is explicitly building on prior work, not redoing it: the
user confirmed the 4 existing findings are a foundation to extend, and they've
already been checked against known single-bank data quirks — don't re-litigate
them from scratch, re-verify them at the larger scale and look for what's new.

### What to do

1. **Re-check the 4 existing findings at 145-bank scale**: leverage-ratio
   reporting-basis change (~FY2022), the large-bank operating-cash-flow swing
   in FY2022, the FY2021→FY2022 LCR softening, and the two capital-ratio
   softening windows (FY2021→22, FY2023→24). With 5x the banks, check whether
   the "majority direction" claims still hold, whether new banks in the
   dataset are consistent or introduce genuine counter-examples worth noting,
   and whether any finding needs its supporting numbers refreshed.
2. **Look for new time-clustered patterns** across the fuller dataset using
   the same method as the original analysis (extract every Cash Flow
   TOTAL row and Pillar 3 headline figure per year across all workbooks, scan
   for same-year moves shared across multiple banks, check candidates against
   known single-bank quirks in `../../Build Effort Review.md` before writing
   them up as findings).
3. **New: within-parent-group comparison**, using IN-002's mapping. For each
   parent group with 2+ built entities (e.g. HSBC's, Lloyds', NatWest's UK
   entities), check whether their metrics move together (shared group-level
   funding/capital policy) or diverge (entity-specific business conditions).
   This is a genuinely new analysis angle the original 29-bank pass couldn't
   do — most parent groups likely didn't have multiple built entities in that
   smaller sample.
4. Keep the existing "Flagged as noise, not signal" and "Notable standalone
   outlier" sections' discipline — a finding only gets written up if it
   survives a check against known single-bank data quirks, not just because a
   number moved.

### Deliverable

An updated `Cross-Bank Trends Analysis.md` (edit in place — this is the same
document, not a new one) with the re-verified/refreshed original findings, any
new time-clustered findings, and the new within-group comparison section.
Keep using IN-001's normalized dataset as the source of truth going forward
rather than re-deriving figures ad hoc from workbooks directly — that's the
whole point of IN-001 existing.
