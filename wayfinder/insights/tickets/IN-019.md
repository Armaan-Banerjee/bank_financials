## Question

Which Power BI interactions would make the summary substantially more useful
without turning exploratory output into unsupported conclusions?

## Scope

- Summary page with field-parameter metric/basis selectors and compact KPI
  coverage/sample-size cards.
- Bank/metric drillthrough page with trend, source notes, basis, period, and
  peer/parent context; report-page tooltips for caveats.
- Distribution/benchmark page with box/strip or percentile views.
- Decomposition tree for exploratory contribution questions.
- Time-series anomaly detection where there are enough comparable observations;
  retain the deterministic IN-009 outlier screen alongside it.
- Bookmarks/navigation for “executive”, “method”, and “investigate” states.

## Completion criteria

- Every visual has a defined denominator and comparability filter.
- Key Influencers/anomaly explanations are labelled exploratory and are not
  presented as causal or compliance findings.
- PDF/export limitations and accessibility fallbacks are documented.

## Progress

Implemented 2026-08-30 as a refreshable Power BI report-experience hand-off.
`scripts/insights/in019_report_experience.py` generates four governed report
pages (executive, comparability, investigation and capital/RWA scale), with
field/measure definitions, denominators, comparability filters, drillthrough
keys, provenance tooltip fields, bookmarks, exploratory/non-causal labels,
accessibility requirements and PDF/export fallbacks. It also generates
`research/powerbi/finding_detail.csv`, retaining the deterministic IN-009
outlier screen alongside exploratory anomaly/decomposition visuals. No native
`.pbix` is generated; the IN-018 semantic model and the HTML/PDF remain the
authoritative data and printable narrative outputs.

The report specification is now a standard refresh step and is covered by
fixture tests for page coverage, denominator/filter completeness, governance
wording, drillthrough keys, and generated hand-off files.

Resolution: IN-019 completion criteria met. The specification is ready for a
Power BI author to build from the IN-018 model; the repository's HTML/PDF
remain the controlled client deliverables.
