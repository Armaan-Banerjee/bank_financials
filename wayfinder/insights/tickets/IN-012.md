## Question

Add the second capital-analysis wave: CET1 Capital, Tier 1 Capital, Total
Capital, and Total RWAs.

## Scope

- Validate units and reporting bases before comparison.
- Provide raw absolute trends.
- Add bank-size segmentation and scale-adjusted peer comparisons where the
  underlying units and bases support them.
- Keep absolute scale distinct from ratio-based peer analysis.

## Completion criteria

- Unit/basis exclusions and coverage are explicit.
- Outputs are database-derived, tested, and suitable for later HTML/PDF use.
- No raw absolute figures are presented as directly comparable across
  currencies, entity bases, or units without an explicit transformation.

## Progress

Claimed for implementation on 2026-08-30. The source data shows that the
absolute Pillar 3 sheets do not have per-row units populated in SQLite, so the
first slice will classify units from explicit source/basis text and leave
unknown units out of cross-bank size comparisons.

The implementation is in `scripts/insights/in012_absolute_analysis.py`. It
produces unit-aware raw trends, each-bank latest observations, same-unit and
same-basis size cohorts, and scale-adjusted capital/RWA relationships in
`research/in012_absolute_analysis.json`.

## Resolution

Closed 2026-08-30. The implementation now:

- classifies amount units conservatively from explicit source text and keeps
  unknown units visible in coverage rather than using them for comparisons;
- retains unit/basis metadata with latest values and emits explicit cohort
  boundaries and insufficient-cohort statuses;
- excludes bank trends when unit or reporting basis changes across years;
- reports scale-adjusted capital/RWA coverage and exclusion reasons;
- writes the JSON artefact atomically and deterministically.

Validation: 149 insights tests pass and the full `refresh_all.py` pipeline
completes successfully, regenerating the database-derived research artefact
and existing HTML/PDF deliverables.
