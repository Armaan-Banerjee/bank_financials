## Question

Build a new script under `scripts/` (e.g. `scripts/extract_metrics.py`) that
reads every workbook in `banks/*.xlsx` and produces one normalized dataset
covering all of them — the shared foundation every other ticket on this map
(`wayfinder/insights/map.md`) depends on, directly or indirectly. This ticket
carries execution, not just a decision — the deliverable is the working script
and its output dataset, committed to `scripts/` and re-runnable on demand.

### What "normalized" means here

For each bank workbook, extract:
- Every Cash Flow Statement `TOTAL`-tagged row, by year (skip entirely for the
  26 Pillar-3-only workbooks — they have no Cash Flow Statement sheet).
- Every headline figure from each of the 11 `PILLAR3_SHEET_NAMES` sheets (see
  `scripts/bank_workbook.py`), by year: CET1 Capital, CET1 Ratio, Tier 1
  Capital, Tier 1 Ratio, Total Capital, Total Capital Ratio, Total RWAs,
  Leverage Ratio, LCR, NSFR, MREL Ratio.
- The bank name (from the filename/sheet content, matched back against `Banks
  List 2608.xlsx` for the canonical entity name and FRN where possible).

Output as long-format rows: one row per (bank, metric, year, value), plus a
flag column for whether the underlying value is a real number or a non-numeric
string like `"Not publicly disclosed"` or `"82.94%"` (percent-strings need
parsing to numeric where the row is meant to be a ratio). Write the result to
a durable file (CSV is a reasonable default — pick whatever's easiest to
re-read from both a clustering script and a one-off analysis pass; do not use
a database unless you have a specific reason a flat file won't do).

### Constraints — do not smooth these over

- **Ignore the 14th "Interim Pillar 3" sheet** where present — annual data
  only for this pass (see the map's Notes on why interim is deferred).
- **Skip the 3 never-built banks** (VTB Capital plc, Bank Of Baroda (UK)
  Limited, Revolut Bank UK Ltd) — there's no workbook to read for them, that's
  expected, not a bug to chase.
- **Preserve currency/basis caveats, don't erase them.** Some workbooks are
  FX-converted (EUR/USD → GBP) or report on a Group rather than
  standalone-entity basis — this is documented in each sheet's source-citation
  cell. Carry forward at minimum a currency/basis flag per bank so downstream
  analysis (IN-003, IN-004) can decide whether to include, exclude, or
  footnote a bank rather than silently mixing bases. You do not need to
  re-derive every nuance from `Build Effort Review.md` — a best-effort flag
  populated from what's readable in each workbook's own citation cells is
  enough; document what you couldn't determine.
- **Missing years are genuinely missing, not zero.** A blank cell in the
  source workbook (per `CLAUDE.md`: "Missing years are left as blank dict keys
  rather than zeros") must come through as a missing/null value in the
  extracted dataset, never as `0`.

### On completion

1. Run the script end-to-end against the current `banks/` directory and
   confirm it produces output for all 145 built banks without crashing on any
   single one (a bank with unusual structure failing loudly with a clear
   error is fine; silently skipping it is not — log skips explicitly).
2. Record a short coverage summary in this ticket's Progress section: how many
   banks/years/metrics got real values vs. missing vs. non-numeric, per
   metric — this is exactly the input IN-003 needs to pick clustering
   dimensions.
3. Post a resolution comment in this ticket's Session log, close the ticket,
   and append a one-line entry to `../map.md`'s Decisions so far.
4. Un-block IN-003 and IN-004 by checking their `blocked_by` is now
   satisfiable (both list IN-001).

## Progress

Built `scripts/extract_metrics.py`. Run against all 145 workbooks in `banks/`
with no crashes; output at `research/bank_metrics.csv` (12,881 rows, one per
bank/sheet/row_label/year).

**Workbook-kind split (ground truth from the actual files, read directly):
126 full / 19 pillar3-only.** This differed from `Build Effort Review.md`'s
stated "119 full + 26 Pillar-3-only" summary line; root cause found and both
fixed at the user's request (2026-08-29) — Morgan Stanley Bank International
Limited was built as Pillar-3-only (FRS 101 exemption, no cash-flow data)
but never labelled as such, undercounting the Pillar-3-only tally by exactly
one against the doc's other 18 correctly-labelled entries. `Build Effort
Review.md`'s summary line and Morgan Stanley's own ranking entry are now
corrected.

**FRN matching**: all 145 banks matched a unique FRN against `Banks List
2608.xlsx`, using each workbook's own sheet-title entity name (not just the
filename) as the primary match key — this was necessary to correctly
disambiguate three real sibling-entity pairs that share a near-identical
filename: Barclays Bank Plc vs Barclays Bank UK PLC/Group, Credit Suisse
(UK) Limited vs Credit Suisse International, and HSBC Bank plc vs HSBC UK
Bank plc. A small hardcoded alias table covers 4 abbreviations no amount of
fuzzy matching could derive (BLME, BNY Mellon International, RBS, UBA UK).

counts among the otherwise-decent sheets, worth checking row-by-row (some of
"missing" there is genuinely-later-adopted metrics, e.g. NSFR only required
from a certain year, not a data gap).
